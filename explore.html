Meaning of terms
Capacity
The amount of water that a reservoir is designed to hold.
Acre-foot
A unit of water volume. One acre-foot covers one acre with water that is one foot deep.
Normal
The middle value for the same time in earlier years. To get this value, put the earlier values in order and select the value in the center.
History rank
A comparison with values near the same date in earlier years. A rank of 90% means that the value is higher than 90% of those earlier values.
Drainage area
The land where the rain and snow that falls on it flows to the same river. A drainage area does not stop at a state border.
Update schedule
How often a source supplies new data.
CSV file
A plain-text file that stores table data.

Storage data comes from the U.S. Bureau of Reclamation and the USDA Natural Resources Conservation Service. The source can change these values later. Some reservoirs use monthly data. Other reservoirs use daily data. Each details panel shows the update schedule.

Capacity data comes from the U.S. Army Corps of Engineers National Inventory of Dams or the USDA Natural Resources Conservation Service.

This dashboard currently contains 54 reservoirs. The two storage sources provide the data for this list.
